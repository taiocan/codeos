    ## Step 1 — Change Intent
    
    ### Problem
    
    In delta-review mode (`--mode delta --base <sha>`), the packet diffs only the explicitly
    named artifact files. Files changed outside the declared list are invisible to the reviewer.
    This means:
    
    - The reviewer cannot answer "did any files change that weren't declared in scope?"
    - Scope drift goes undetected — the reviewer cannot flag `backlog/features.md` changed but
      not in the artifact list (the UPG-0015 Step-4 R1 case that required a human correction)
    - The diff-review checklist in `docs/workflow-profiles.md` ("Unrelated files?", "Approved
      artifacts modified after approval?") is unanswerable from the evidence alone
    
    ### What changes
    
    | File | Change |
    |---|---|
    | `tools/reviewer/src/packet.rs` | When `--all-diff` + `delta_base` present: append "Full Context Diff" section to packet (`git diff <base>` of all changed files, size-clipped to remaining budget) |
    | `tools/reviewer/src/cmd/review.rs` | Parse and thread `--all-diff` flag into `PacketOpts` |
    | `tools/reviewer/src/main.rs` | Add `--all-diff` to review subcommand arg list |
    | `tools/reviewer/tests/smoke.rs` | Tests: full-diff section present in packet; absent without `--all-diff`; size budget respected; backward-compat (no flag = unchanged behavior) |
    | `scripts/codeos-review.sh` | Auto-pass `--all-diff` when `--mode delta --base <sha>` is active |
    | `docs/reviewer-pipeline.md` | Document `--all-diff` capability, when it fires, and size behavior |
    | `backlog/UPG-0014-reviewer-full-diff.md` | Feature Thread updated |
    | `status/self-development.md` | Row activated |
    | `status/roadmap.md` | UPG-0014 → IN_PROGRESS |
    
    ### Scope boundary — what stays the same
    
    - Named artifact evidence in the packet — backward-compatible; `--all-diff` is additive
    - Reviewer advisory and non-gatekeeping status — unchanged; diff is evidence only
    - Secret filtering and size budget — full diff obeys the same `CODEOS_PACKET_BUDGET_BYTES`
      cap; clipped with an explicit note if over budget
    - `dba-system.md` — not touched
    - Decision/log/provenance code (`cmd/decision.rs`, `log.rs`) — not touched
    - The five reviewer "mode" names from the brief (Artifact, Diff, Test, Runtime,
      Pre-Release) — not formalized in this increment; Diff Review is achieved by using
      `--all-diff` in the existing review command
    
    ### Behavior
    
    When `--all-diff` is passed to `codeos-reviewer review --base <sha>`:
    
    1. After building the named-artifact packet content (unchanged), compute remaining budget.
    2. Run `git diff <base>` with no path filter (all changed files).
    3. If the diff fits in remaining budget: append a `Full Context Diff (git diff <base>):` section.
    4. If the diff exceeds remaining budget: clip at the budget limit and append a note:
       `[CLIPPED: full diff exceeded packet budget — showing first N bytes]`.
    5. The section is labeled so the reviewer can distinguish it from named-artifact content.
    
    When `--all-diff` is NOT passed: packet is identical to today (backward-compatible).
    
    In `scripts/codeos-review.sh`: `--all-diff` is passed automatically when both `--mode delta`
    and `--base <sha>` are active.
