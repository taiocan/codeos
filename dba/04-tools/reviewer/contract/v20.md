# Reviewer Tool Contract — v20

v20 incorporates v19. A Codex-backed assessment additionally records the approved release model
identifier, Codex CLI version, reasoning effort, session identity, reviewer build identity, and
Codeos release identity. The invocation passes the approved model explicitly and fails closed when
the CLI differs from the active release identity. Updating that identity is a release-qualified
human decision, not a new review workflow or approval authority.
