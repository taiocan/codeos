# Reviewer Tool Contract — v14

Reviewer Tool Contract v14 retains v13 and implements Review Policy v12.

`audit-review-applicability <feature> 8 --review-id <id>` deterministically compares the immutable
review packet and assessment with the authoritative pre-execution F6 selection and canonical
implementation/evidence bindings. It appends `INVALID_REVIEW_INPUT_LINEAGE` only for a complete,
progression-permitting assessment with at least one permitted mechanical contradiction. The record
contains the target assessment and packet identities, package-cycle identity, reason codes,
authoritative and reviewed evidence identities, canonical implementation identities, and its own
SHA-256. Repeating the audit cannot create another record.

`decision ... AUTHORIZE_LINEAGE_REPLACEMENT --after-review <id>
--applicability-record-sha <sha>` records one human authorization only when the cited immutable
applicability record is valid and no replacement or later `STOP` exists.

`review ... --replace-invalid-lineage-after <id>` executes the replacement once. Before invoking
the reviewer it requires a clean committed implementation baseline, unchanged approved package and
architecture identities, current verification, an explicit current F6 selection, the exact
selected production artifact, matching canonical implementation bindings, and complete mandatory
Stage 8 context. It rejects conflicting binding claims in supplied evidence.

The replacement packet includes the invalid assessment and applicability record only as immutable
provenance, the original authorized semantic scope, complete current governed context, current
implementation surface, and current evidence. It instructs the reviewer to assess the scope anew
without inheriting the invalid conclusion. The tool refuses a second execution, scope drift,
changed governed meaning or architecture, a missing or conflicting binding, an unfavorable target,
or any use under another contract.

Before every reality-dependent Stage 8 review, the v14 reviewer also validates that the packet's
production evidence is exactly the current F6 selection and that its implementation and governed
bindings are canonical. This prevention check occurs before semantic reviewer invocation.
