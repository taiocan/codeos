# Reviewer Tool Contract — v24

v24 incorporates v23. Under Feature Workflow v16, each Contract scenario may cover or contribute to
Charter obligations. A Stage 2, 3 or 5 packet adds a Charter Obligation Projection: for every
`covers:` and `contributes:` entry of the reviewed feature's Contract, the scenario ID, the relation,
the obligation ID and the exact normalized row text of that obligation in the current Charter, with
the Charter's SHA-256. An ID absent from the Charter is shown as such.

At Stages 2 and 3 the projection asks whether a realistic implementation violating the exact clause
could still pass every covering scenario, whether an obligation depending on several features has an
integrated product-journey scenario, and whether a compound clause hides an uncovered condition. At
Stage 5 it shows each covering scenario's test tag and asks whether the tagged tests exercise the
scenario's specified behavior.

The projection adds no required input and changes no readiness rule. Allocation, specification and
verification state remain the workflow checker's derivation. The reviewer's judgment stays advisory.
