# Reviewer Tool Contract — v23

v23 incorporates v22. Feature Workflow v13 satisfies an `observation:human` validation claim only by
an explicit outcome in a sealed Human Validation Session, so that session is the claim's evidence and
belongs in the Stage 8 required input set.

For every `observation:human` claim of the reviewed feature, the Review Input Manifest includes the
sealed session that the latest receipt of the claim's checkpoint binds, when that session is intact
and attests the receipt: `.codeos/06-workflow/sessions/<sha256>.json`, shown whole. A claim with no
such session fails readiness with `REQUIRED_INPUT_MISSING`, naming the claim, before any Codex
execution.

Whether the claim is satisfied remains the workflow checker's decision. The session stays bound by
its content-addressed SHA-256, and the reviewer's judgment of it stays advisory.
