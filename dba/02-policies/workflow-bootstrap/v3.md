# Solution Bootstrap Workflow Contract — v3

v3 incorporates v2 and adapts B3 to the persistence engine the Platform Baseline resolves
(Doctrine v10).

## B3 with SQLite persistence

When `codeos.yaml` resolves `persistence: sqlite`, the B3 conditions "PostgreSQL starts" and "A clean
SQLx migration succeeds from an empty database" are replaced by one condition: the project's own
migrations create a new, empty file-backed SQLite database cleanly. The project-native
`runtime_verification.verification_command` executes B3 and reports the result. Conditions for
tiers the Charter records as not applicable drop as in v1.

With `persistence: postgresql`, B3 is unchanged.

## Compatibility

Workflow Bootstrap v1 and v2 behave as issued. Everything else in v2 is unchanged.
