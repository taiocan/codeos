# Feature Development Workflow Contract — v4

v4 incorporates v3 in full.

F6 reconciliation is bound to the current implementation and resolved DBA configuration as well as
the approved Specification Package and selected production evidence. Drift in any binding makes F6
stale and requires explicit reconciliation.

A review carrying an immutable `INVALID_REVIEW_INPUT_LINEAGE` applicability record contributes no
meaning to F7 even when its execution was complete and its reviewer conclusion would otherwise
permit progression. F7 may instead use one complete, progression-permitting
`LINEAGE-REPLACEMENT-1` only when the immutable history satisfies Review Policy v12 and the
replacement packet is bound to the current F6-selected production evidence.
