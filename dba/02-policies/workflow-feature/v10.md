# Feature Development Workflow Contract — v10

v10 incorporates v9 and defines the feature-scoped product binding that v8 requires for the F4
Early Development Preview and F8 Final UX Validation receipts.

For a GUI feature, that binding is its Observed Surface. The feature's governed browser journey,
the F3 `product_journey` run, records the normalized accessibility state and layout geometry of
every element it observes or asserts, at each viewport it runs at. The observation must be
reproducible from the same governed fixture inputs: this journey runs twice, in the project's
deterministic provider mode, and the two identities must match or the verification fails.
Production-source evidence is never repeated for this purpose. F4 and F8 bind that identity instead of the
project-wide product state. A receipt is current only while the current journey verification
reproduces the identity it bound; an absent or non-reproducible observation fails closed. Codeos
infers nothing beyond what the journey observes. The project owns the journey, its viewports, and
the deterministic provider mode it runs in.

A feature without a governed browser journey keeps binding the project-wide product state. A
receipt recorded under an earlier version keeps the binding it recorded and stays current while
that binding is unchanged.

## Observation protocol

Codeos names a file in `CODEOS_OBSERVED_SURFACE_PATH`. For each observed state, the journey
appends one JSON line:

```json
{ "schema": 1, "state": "<stable label>", "viewport": { "width": 1280, "height": 720 },
  "elements": [ { "name": "<stable label>", "aria": "<accessibility snapshot>",
                  "box": { "x": 0, "y": 0, "width": 0, "height": 0 } } ] }
```

Codeos reads only that file. It trims accessibility text, rounds geometry to whole CSS pixels,
orders observations by state and viewport, and derives the identity from the result. A malformed
line, a missing or empty file, or one state observed twice at one viewport with different content
fails the verification.

F6 Reconciliation, F7, F9 Acceptance, Candidate Bundle invalidation, and all v9 semantics are
unchanged.
