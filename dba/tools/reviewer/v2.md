# Reviewer Tool Contract — v2

## Reviewer Invocation

**How to run it.** At each review point governed by the selected review policy, run:
```
.codeos/scripts/codeos-review.sh review <feature_id> <stage>
```
Use Stage ID `3` for the complete Specification Package. The Stage-3 packet evaluates Intent,
Contract, Event Schema, and their consistency.

## Supported Wrapper

**The wrapper is the supported entry point.** Use `.codeos/scripts/codeos-review.sh` downstream and
`scripts/codeos-review.sh` for Codeos self-development. The wrapper resolves the compiled reviewer
binary relative to the toolkit and delegates the requested subcommand.

## Architecture Inspection Utility

`inspect-architecture-scopes [--feature <feature_id>]` is a deterministic, read-only utility hosted
by the existing reviewer binary to avoid another executable. It validates Architecture Scope
metadata and reports membership plus recorded approval state. It invokes no reviewer, produces no
verdict, and has no approval or architecture-decision authority.
