    ## Design notes
    
    ```markdown
    # Readiness Checklist
    
    Feature:
    Branch:
    Commit:

    - Tests run:
    - Tests skipped explained:
    - CI status:
    - No unrelated files:

    - Docs updated if needed:
    - Stack/config manifest checked if dependency/config changed:

    - Rollback/revert path known:
    ```
