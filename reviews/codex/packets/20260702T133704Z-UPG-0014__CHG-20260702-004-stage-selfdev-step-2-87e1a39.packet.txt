    ## Step 1 — Change Intent
    
    ### Problem
    
    In delta-review mode (`--mode delta --base <sha>`), the packet diffs only the explicitly
    named artifact files. Files changed outside the declared list are invisible to the reviewer.
    This means:
    
    - The reviewer cannot answer "did any files change that weren't declared in scope?"
    - Scope drift goes undetected — the reviewer cannot flag `backlog/features.md` changed but
      not in the artifact list (the UPG-0015 Step-4 R1 case that required a human correction)
    - The diff-review checklist in `docs/workflow-profiles.md` ("Unrelated files?", "Approved
      artifacts modified after approval?") is unanswerable from the evidence alone
    
    ### What changes
    
    | File | Change |
    |---|---|
    | `tools/reviewer/src/packet.rs` | When `--all-diff` + `--base <sha>` present: append `Full Context Diff (informational — all changed files since <base>):` section (`git diff <base>` of all changed files, size-clipped to remaining budget) |
    | `tools/reviewer/src/cmd/review.rs` | Parse and thread `--all-diff` flag into `PacketOpts` |
    | `tools/reviewer/src/main.rs` | Add `--all-diff` to review subcommand arg list |
    | `tools/reviewer/tests/smoke.rs` | Tests: full-diff section present in packet; absent without `--all-diff`; size budget respected; backward-compat (no flag = unchanged behavior) |
    | `scripts/codeos-review.sh` | Auto-pass `--all-diff` when `--mode delta --base <sha>` is active |

    - Reviewer advisory and non-gatekeeping status — unchanged; diff is evidence only
    - Secret filtering and size budget — full diff obeys the same `CODEOS_PACKET_BUDGET_BYTES`

    ### Behavior
    
    **Rust-level activation:** `--all-diff` + `--base <sha>` are both present. `--mode` is
    independent — `--all-diff` works with either `--mode full` or `--mode delta`; it only
    requires a base commit to diff against.
    
    When active:
    1. After building the named-artifact packet content (unchanged), compute remaining budget.
    2. Run `git diff <base>` with no path filter (all changed files).
    3. If the diff fits in remaining budget: append a section labeled:
       `Full Context Diff (informational — all changed files since <base>):`
    4. If the diff exceeds remaining budget: clip at the budget limit and append:
       `[CLIPPED: full diff exceeded packet budget — showing first N of M bytes]`
    5. The "informational" label distinguishes it from the declared artifact scope.
    
    When `--all-diff` is NOT passed: packet is identical to today (backward-compatible).
    
    **Bash-level auto-pass (`scripts/codeos-review.sh`):** `--all-diff` is passed automatically
    when BOTH `--mode delta` AND `--base <sha>` are active. Using `--mode delta` without `--base`,
    or `--base` without `--mode delta`, does not trigger auto-pass.

    ## Step 2 — Acceptance Criteria
    
    Each criterion is independently verifiable against the implementation.
    
    ### AC-1 — Full diff section appears when `--all-diff` + `--base <sha>` are both present
    
    The "Full Context Diff" section appears in the packet if and only if both `--all-diff` and
    `--base <sha>` are passed to `codeos-reviewer review`. The `--mode` value is independent —
    the flag works with `--mode full` and `--mode delta` alike, since `--base` is the only
    necessary reference point. Without `--base`, `--all-diff` must be a no-op (no base to diff
    against). Verified by testing: with both flags → section present; with only one → section
    absent.
    
    ### AC-2 — Without `--all-diff`, packet is structurally unchanged
    
    Running `codeos-reviewer review` without `--all-diff` (regardless of `--mode delta`) produces
    a packet with no "Full Context Diff" section and no change to any existing field or section.
    The content of all existing sections is identical to pre-change behavior.
    
    ### AC-3 — Full diff is additive; named-artifact section is not replaced or modified
    
    The named-artifact content section (file contents or per-artifact diffs in delta mode) is
    present and unmodified when `--all-diff` is also active. The full diff is appended as a
    separate labeled section after the named artifacts.
    
    ### AC-4 — Budget clipping is explicit
    
    When the full diff exceeds the remaining packet budget, the section is clipped at the budget
    limit and terminated with a clearly labeled marker:
    ```
    [CLIPPED: full diff exceeded packet budget — showing first N of M bytes]
    ```
    No truncation is silent. An unclipped full diff carries no such marker.
    
    ### AC-5 — Secret redaction applies to the full diff
    
    If `CODEOS_REDACT_PATTERNS` (or equivalent secret filtering) is configured, the full diff
    passes through the same redaction pipeline as named artifacts. Any redacted span in the
    full diff increments the packet's `redaction_count` and is replaced with `[REDACTED]`.
    Verified by grep of the redaction call site confirming the full diff passes through it.
    
    ### AC-6 — Bash wrapper auto-passes `--all-diff` only when `--mode delta` AND `--base` are both active
    
    `codeos-review.sh` passes `--all-diff` to `codeos-reviewer review` if and only if BOTH
    `--mode delta` AND `--base <sha>` are active in the bash invocation. Using `--mode delta`
    without `--base`, or `--base` without `--mode delta`, does NOT trigger auto-pass. (Note:
    this is more restrictive than the Rust-level activation in AC-1, which only requires
    `--base`. The bash wrapper restricts auto-pass to the case where delta mode is explicit.)
    
    ### AC-7 — Reviewer scope contract is not widened
    
    The full diff section carries a label that distinguishes it from the declared artifact scope:
    `Full Context Diff (informational — all changed files since <base>):`. The reviewer is NOT
    told to treat the full diff as the authoritative scope list. The declared artifacts remain
    the canonical scope contract; the full diff is supplementary context.
    
    ### AC-8 — Tests pass
    
    `cargo test` passes with tests covering at minimum:
    - AC-1: full diff section present when `--all-diff` + delta + base
    - AC-2: no full diff section when `--all-diff` absent
    - AC-3: named artifact section unchanged with and without `--all-diff`
    - AC-4: clipping marker present when diff exceeds budget; absent when within budget
