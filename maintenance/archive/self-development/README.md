# Archived Codeos Self-Development Records

This directory preserves records from the retired four-step Codeos self-development process. They
are historical evidence, not active workflow instructions or current operational state.

- `changes/`: former `CHG-*` execution records and supporting evidence.
- `backlog/completed/`: completed, closed, or superseded upgrade briefs.
- `reviews/`: historical reviewer packets, assessments, and the former review log.
- `status/`: former dashboard, roadmap, stack manifest, and reconciliation report.
- `retired-process/`: the former mandatory workflow prompt and change-record template.
- `design-history/`: completed design material retained for provenance.

Current self-development governance is in the repository-root `CLAUDE.md`. Current planned work is
listed in `backlog/features.md`. Do not update archived records to reflect current work.
